# MAP Journee - Mobile App Presentation

This repository contains the presentation version of MAP Journee, a mobile application for journaling and travel documentation.

## Features
- Journal Entry Management
- Media Integration
- Calendar View
- Atlas/Map Integration
- Profile Management

## UI Components
- Modern Material Design implementation
- Custom theme and color schemes
- Responsive layouts for various screen sizes
- Interactive user interface elements

## Technical Stack
- Kotlin
- Jetpack Compose
- Android Architecture Components
- Material Design 3
